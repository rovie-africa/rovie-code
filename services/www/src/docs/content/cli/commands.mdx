title: "Commands"
description: "Reference for the rovie command line."
---

Every command accepts `--help` for its full flag list, for example `rovie run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ rovie run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Rovie Code review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: rovie run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ rovie run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ rovie run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ rovie run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ rovie run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ rovie run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ rovie run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ rovie run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ rovie run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ rovie mini
```

Continue the last session.

```bash
$ rovie mini --continue
```

Start with a model and an initial prompt.

```bash
$ rovie mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ rovie mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ rovie mini --help
```

## session

Manages sessions.

```bash
$ rovie session list
```

Limit the list and print JSON.

```bash
$ rovie session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ rovie session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ rovie session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ rovie session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ rovie session import session.json
```

Import into a specific directory.

```bash
$ rovie session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ rovie session --help
```

## auth

Manages AI providers and credentials.

```bash
$ rovie auth list
```

List them as JSON.

```bash
$ rovie auth list --format json
```

Log in to a provider.

```bash
$ rovie auth login anthropic
```

Log in with a specific authentication method.

```bash
$ rovie auth login anthropic --method key
```

Log out of a saved account.

```bash
$ rovie auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ rovie auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ rovie auth export anthropic > credentials.json
$ rovie auth import credentials.json
```

View all subcommands and flags.

```bash
$ rovie auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ rovie mcp list
```

Add a remote server.

```bash
$ rovie mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ rovie mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ rovie mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ rovie mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ rovie mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ rovie mcp logout sentry
```

View all subcommands and flags.

```bash
$ rovie mcp --help
```

```bash

```



```bash
$ rovie plugin check
```

```bash
$ rovie plugin update
```

Remove a plugin from global configuration.

```bash
$ rovie plugin remove @example/rovie-tui
```

View all subcommands and flags.

```bash
$ rovie plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ rovie serve
```

Bind to all interfaces on a fixed port.

```bash
$ rovie serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ rovie serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ rovie serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ rovie pair
```

Use an external URL in the links.

```bash
$ rovie pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ rovie pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ rovie pair --remote --yes
```

View all subcommands and flags.

```bash
$ rovie pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ rovie service start
```

Restart it.

```bash
$ rovie service restart
```

Show its status.

```bash
$ rovie service status
```

Stop it.

```bash
$ rovie service stop
```

Read a setting.

```bash
$ rovie service get hostname
```

Set a setting.

```bash
$ rovie service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ rovie service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ rovie service set env ROVIE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ rovie service unset hostname
```

View all subcommands and flags.

```bash
$ rovie service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ rovie reload
```

## api

Makes a request to the running server.

```bash
$ rovie api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ rovie api session.list --param limit=10
```

Send a JSON body.

```bash
$ rovie api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ rovie api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ rovie api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ rovie debug agents
```

List configuration sources.

```bash
$ rovie debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ rovie debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ rovie debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ rovie debug paths
```

Print a single path.

```bash
$ rovie debug paths db
```

View all subcommands and flags.

```bash
$ rovie debug --help
```

## upgrade

Upgrades Rovie Code to the latest or a specific version. Alias: `update`.

```bash
$ rovie upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ rovie upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ rovie upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Rovie Code. Session data, configuration, and
state are not removed.

```bash
$ rovie uninstall
```

Preview what would be removed.

```bash
$ rovie uninstall --dry-run
```

View all subcommands and flags.

```bash
$ rovie uninstall --help
```
